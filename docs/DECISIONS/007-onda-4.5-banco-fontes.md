# ADR 007 — Onda 4.5: Banco de Fontes Curado

**Data:** 2026-05-05  
**Status:** Aceito

---

## Contexto

Onda 4 fechou com fitText funcional mas usando fallback `system-ui` (Times no Windows) porque `@font-face` não estava carregando as 14 fontes do seed da Onda 1 — todas com `file: null` apontando para Google CDN.

Esta onda substitui as 14 fontes legacy por 5 curadas para o nicho profissional, embutidas como arquivos `.ttf` locais no bundle Tauri, carregadas ativamente via FontFace API.

Migration `0001_curated_fonts.sql` (modificada) faz `DELETE FROM fonts` e reinsere apenas as 5 curadas. As 14 fontes não-curadas do seed original foram descartadas. Decisão deliberada do Gabriell.

### Asset protocol Tauri 2.x é OPT-IN

Em Tauri 1.x, `http://asset.localhost/` funcionava automaticamente. Em Tauri 2.x é necessário habilitar explicitamente em `tauri.conf.json`:

```json
"security": {
  "csp": null,
  "assetProtocol": {
    "enable": true,
    "scope": ["**"]
  }
}
```

Sem `enable: true` → `ERR_CONNECTION_REFUSED`.  
Com `enable: true` mas scope incorreto → `403 Forbidden`.

Scope atual `["**"]` libera acesso ao filesystem inteiro via asset protocol. Trade-off aceito para MVP local (single-user, sem internet). **Pré-release:** trocar por `["$RESOURCE/**"]` após validar sintaxe em build de produção.

### `@font-face` passivo gera falso negativo — usar FontFace API

`@font-face` no CSS faz lazy-load: o browser só baixa a fonte quando algum elemento da página a usa. `document.fonts.check('16px Montserrat')` retorna `false` enquanto nenhum elemento usa a fonte, mesmo com a regra CSS injetada e o arquivo acessível.

Solução: carregar ativamente via FontFace API:

```typescript
const fontFace = new FontFace(f.family, `url(${url})`, { weight });
const loaded = await fontFace.load();
document.fonts.add(loaded);
```

Isso força o download síncrono e garante disponibilidade imediata para `fitText` e qualquer elemento da UI, sem depender de um elemento renderizando com aquela fonte.

### Cargo não detecta mudanças em `resources/`

Adicionar ou renomear arquivos em `src-tauri/resources/` **não dispara rebuild automático**. Cargo monitora arquivos `.rs`, não assets. Para forçar a cópia de novos assets para `target/debug/resources/`:

```bash
cargo clean   # dentro de src-tauri/
npm run tauri dev
```

Isso é obrigatório sempre que novas fontes ou texturas forem adicionadas.

## Lições aprendidas — diagnóstico da Onda 4.5

A onda exigiu 6 rounds de diagnóstico antes de identificar a causa raiz real. Hipóteses queimadas em ordem:

1. **Colchete `[wght]` no nome do arquivo** — renomeado para `-Variable.ttf`, mas não era a causa
2. **`format('truetype')` rejeita variable fonts** — não testada diretamente (hipótese pulada)
3. **Path do banco `fonts/X` → `resources/fonts/X`** — migration 0003 corrigiu, mas problema persistiu
4. **Cargo clean / build cache desatualizado** — fonts copiadas para `target/debug/resources/fonts/`, mas problema persistiu
5. **`bundle.resources` config** — não era; glob `"resources/**/*"` já cobria tudo
6. **Asset protocol scope `$RESOURCE/**`** — 403 Forbidden; trocado por `["**"]`→ 200 OK; mas`document.fonts.check()`ainda retornava`false`

**Causa raiz real:** `document.fonts.check()` retorna `false` para fontes em lazy-load. Bebas Neue retornava `true` porque é fonte do Windows OS — falso positivo que mascarou o problema em todos os rounds.

**O que revelou a causa real:** diagnóstico verificativo com 4 comandos no console DevTools (D1–D4):

- D1: CSS do `#capi-font-loader` — confirmou @font-face injetado
- D2: `Array.from(document.fonts)` — mostrou todas as 5 custom fonts em `status: 'unloaded'`
- D3: `fetch(url)` direto — `ERR_CONNECTION_REFUSED` → depois `403` → depois `200 OK`
- D4: `new FontFace(...).load()` — confirmou a falha de carregamento em cada etapa

**Princípio registrado:** quando hipóteses sucessivas falham, parar de chutar e exigir dados crus do sistema (fetch direto, status de FontFace, logs de rede).

## Consequências

- **Onda 5 (texturas):** asset protocol já configurado. Mas ao adicionar PNGs em `resources/materials/`, executar `cargo clean` antes do `tauri dev`.
- **Onda 10 (Banco de Ativos > Fontes):** UI de gerenciamento, upload manual, preview rico — os 5 registros atuais são base.
- **Pré-release:** revisar `scope: ["**"]` do asset protocol para algo mais restrito. Testar `["$RESOURCE/**"]` em build de produção (`.msi`).
